# 人才发展数据库 · 国际升学与学术研究

一个单文件的静态数据库网站，对应「人才发展数据库」设计中的第 3、4 部分。

## 内容

| 分组 | 表 | 记录数 |
|---|---|---|
| 国际升学（8 字段） | 国家地区 / 院校项目 / 申请时间线 / 奖学金 / 毕业去向 / 学位政策 | 6 张 / 69 条 |
| 学术研究（9 字段） | 学科方向 / 细分主题 / 经典文献 / 研究方法 / 数据库工具 / 典型问题 / 课题组项目 / 成果评价 / 职业路径 | 9 张 / 198 条 |

合计 15 张表、267 条记录，全表无空单元格。

## 功能

- 全局搜索（当前表所有列，命中高亮）
- 按列筛选（自动识别「验证状态」列）
- 点击表头排序（数字列按数值、文本列按拼音）
- 导出 CSV（当前筛选结果，带 BOM）
- 深链接（`#08_学术_细分主题` 可直接分享）
- 响应式（桌面 / 平板 / 手机三档无横向滚动）

## 数据标记

- **●** 官网原文 —— 已抓取目标院校官方页面的原文数据（NUS、NTU 两项）
- **▲** 未取得原文 —— 页面超时 / SSL 拦截 / Cloudflare 403 / 纯 JS 渲染，数字为公开量级区间
- **◐** 政策类 —— 政策文件可查但年年调整

抓取失败的院校及其具体原因（超时、404、Cloudflare 拦截等）逐条记录在「核验说明」列，未做模糊处理。

## 技术

单文件 HTML，零外部依赖，无构建步骤。数据以 JSON 内嵌，前端为原生 JavaScript。

## 更新方式

用 Excel 版《国际升学与学术研究数据库》维护数据，重新导出 JSON 并替换 `index.html` 中的 `const DB = ...` 即可。
